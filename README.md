1. ZIP-Datei entpacken.
2. Die Datei history-analyzer-ad-coach-3.1.1.user.js öffnen.

4. Auf Installieren klicken.

Wichtig:
Vorher ältere Versionen des History Analyzers in Tampermonkey deaktivieren oder löschen.
